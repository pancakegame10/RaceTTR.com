Two classes, one program

a spec four-stroke and a shifter-adjacent sprint kart, run out of the same trailer

LO206

A sealed, spec four-stroke engine — the field is decided by driver skill and chassis setup, not budget. This is where our program builds race craft.

KA100

A faster, higher-revving class that rewards precision on corner entry and consistent lap-after-lap pace. Our step up in outright speed.

Data & setup

Every session is logged — lap times, sector splits, tire and chassis notes — so changes are made on evidence, not guesswork.
